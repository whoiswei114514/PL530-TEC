# PCB 工程

`PL530.epro2` 为原始 PCB 工程，保留电路与布线内容。

请使用嘉立创EDA/EasyEDA 专业版客户端导入 `.epro2` 文件。仓库提供原生工程，不提供 KiCad、Altium 等格式。

样机已完成连续 **30 分钟烤机测试**，运行稳定，激光输出维持单纵模、未出现跳模，功率稳定。

接线、供电、装配和历史检查记录见 [硬件与实测](../docs/硬件与风险.md)。复刻或修改工程时，请完成网表核对与 ERC/DRC。
