# PCB 工程

`PL530.epro2` 是完整的原始 PCB 工程，里面包含了电路原理图、布线和内嵌图片。

请使用嘉立创 EDA / EasyEDA 专业版客户端导入打开。仓库只放了原生工程文件，没有再另外导出 KiCad、Altium 或旧版 Gerber，避免多个格式版本之间打架。

接线、供电和踩坑记录见 [硬件与实测](../docs/硬件与风险.md)。复刻打样或改板前，建议自己再核一遍网表并跑一次 ERC/DRC。
