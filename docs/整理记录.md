# 整理记录

记录一下这套板子和固件从早期原型到开源整理期间的几轮迭代，方便对照代码和硬件版本。

## 硬件与固件演进

1. **早期方案弃用**：最早试过 ESP32-S3 + BMP280 + AT8236，后来改成了高精度测温的 TMP117 和 DRV8701P 外置 NMOS H 桥，旧方案已经不再支持。
2. **2026-09 架构与现场调通**：9 月中旬完成方向检测、NVS 持久化、网页停机和请求来源保护等核心逻辑；22~24 日实机排查了串口/飞线下载、GPIO8/9 软件 I2C 线序自动探测、LEDC 与故障初始化，并修掉电荷泵 `C2` 虚焊（补焊后 `VCP` 升到约 21.5 V），跑通反向 PWM 降温测试，也定位过一次正向触发 `nFAULT` 的问题。
3. **控制参数定型**：后续源码把 PWM 定在 1 kHz / 10 位，改用低速软件 I2C、补上驱动唤醒等待和 30% 方向检测限幅，并加上了采样超时恢复后自动继续之前启停状态的逻辑。

## 2026-11 开源整理与收口

- **拆分普通与调试固件**：默认 `pl530_tec` 关闭高危直通调试，独立出 `pl530_tec_debug` 环境专门留给台架手调；debug HTTP 修改接口补全了 `X-PL530-Request: 1` 请求头与 Host/Origin 校验，HTTP 手动设置方向补上了运行状态和保存结果检查。
- **修掉交互与注释细节**：修好了方向检测期间主循环不响应 HTTP 查询和停止请求的问题；状态接口改回真实返回 `pulseMs` 与 `dutyLimitPercent=30`，删掉了网页确认框里误导性的“三秒全功率”旧文案；顺手更正了 DRV8701P 双低输入实际为高阻滑行的代码注释。
- **补齐测试与实测记录**：补充了控制器、传感器、NVS 存储、接口 handler 和 Playwright 网页自动化测试以及 GitHub Actions CI；11 月 8 日补充了样机连续 30 分钟烤机、服务器散热器装配与干涉条纹测试实拍（把之前误标成“绿色光斑”的图注一并改对）。
- **新增独立精密 PID 实验版**：11 月 8 日在 `firmware/precision_pid/` 单开了一套 PlatformIO 工程，采用按真实 dt 计算的双向 PID、测量微分、抗积分饱和、TMP117 八次硬件平均、14 位 PWM、独立 NVS 以及未滤波串口日志分析脚本，目前仅过软件测试与仿真，还没上板实测。根目录原版源码、配置与 PCB 工程均保持原样。具体测试与验证范围见 [发布验证](发布验证.md)。
