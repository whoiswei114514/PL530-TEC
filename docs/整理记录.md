# 整理记录

整理日期：2026-11-07。

## 来源

本次读取了原项目设计聊天、编译烧录调试聊天的本地存档，并对照原固件目录以及 Google Antigravity 的后续交付记录。没有把私人聊天原文、临时日志或设备标识打包公开。

1. 早期设计使用 ESP32-S3、BMP280、AT8236，随后更换为 TMP117 与 DRV8701P 外置 H 桥。早期方案不再是本仓库目标。
2. 2026-09-14 至 2026-09-20 的工作包括硬件审查、方向检测、持久化、网页停止和请求来源防护。历史审计还保留槽距及网表提示。
3. 2026-09-22 至 2026-09-23 的现场调试包括串口与原生 USB 下载、TMP117 总线排查、GPIO8/9 顺序探测、软件 I2C、LEDC 与故障初始化修正。
4. Antigravity 的 2026-09-24 记录包含电荷泵 C2 补焊、反向 PWM 降温、正向 nFAULT 故障排查，以及 UART/HTTP 手动调试。
5. 本地后续源码进一步调整 PWM 为 1 kHz、低速软件 I2C、唤醒等待、检测时序和占空比限幅，并加入温度恢复自动重新控制。发布以实际源码为准，不以旧报告的文字为准。

## 本次保留

- TMP117 软件 I2C 与交换 GPIO8/9 的探测。
- 1 kHz、10 位 PWM，DRV8701P 外置 H 桥配置。
- 原非线性接近与热平衡调节算法，没有整体重写 PID。
- 参数与方向持久化、中文网页、正常 HTTP 接口。
- 原有强制唤醒、直接 PWM、手动方向与 UART 调试能力。
- 控制器、传感器、存储、接口和浏览器测试。
- 用户指定的 `.epro2` PCB 原文件。

## 本次调整

- 普通环境默认关闭不安全 debug，另设 `pl530_tec_debug` 构建，接口与串口命令仍保留。
- debug HTTP 修改接口增加请求头与来源校验，手动 HTTP 方向设置检查输入、运行状态、保存及应用结果。
- 方向检测期间继续服务 HTTP，恢复网页状态查询与停止请求的路径，增加主循环回归测试。
- 状态接口返回实际脉冲时长及限幅，网页确认框不再宣称固定“三秒全功率”。
- 修正把 DRV8701P 的双低输入误描述为低侧制动的注释；实际为高阻滑行。没有据此擅自改变功率换流实现。
- 清理过时文档与本机测试依赖路径，新增可复现的测试入口、自动验证与中文文档。

原工程目录没有覆盖或删除。本仓库是独立整理副本，不混入旧二进制镜像、仿真波形、下载模式恢复脚本和历史快照。
