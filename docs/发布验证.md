# 发布验证

原版整理与全套软件测试记录：2026-11-07 ~ 2026-11-08；2026-11-11 开源协议切换为 GPLv3（`GPL-3.0-only`）；本次仅润色文档并同步更新 [发布清单](发布清单.json) 的文件校验值，未改动任何固件源码、依赖版本或构建配置，下方编译与测试记录对应 2026-11-08 的实跑结果。

## 样机实测

原版固件在实物样机上已经完成连续 **30 分钟烤机测试**，运行稳定，激光全程维持单纵模、未出现跳模，输出功率稳定。装配与干涉条纹实拍见 [硬件与实测](硬件与风险.md#实测表现)。

放在 `firmware/precision_pid/` 下的精密 PID 实验版**目前仅通过热模型仿真与软件回归测试，尚未上板实测**，±10 mK 为后续实机整定目标。

## 测试范围

主机 C++ 测试通过 Mock 替换了外设、NVS 和网络栈，编译时定义了 `ARDUINO` 与 `ESP32`，未定义 `ESP_PLATFORM`；因此实机专属分支里的启动等待、故障毛刺过滤、30% 检测限幅（主机测试沿用默认 3 秒脉冲，实机为 4 秒脉冲）和停机延时，需在上板测试时确认。

接口测试调用的是真实 `main.cpp` 请求处理函数配合虚拟外设；网页测试通过 Playwright 网络拦截模拟设备响应。热模型仅用于检查 PID 与抗饱和算法逻辑，新版是否达到 ±10 mK 稳态以实机录制的串口原始温度日志为准。

`node tools/verify_release.mjs` 用来校验仓库文件与 [发布清单](发布清单.json) 的哈希是否匹配；修改代码、依赖或构建配置后，完整跑完测试与三套编译再用 `--write` 重建完整清单。近期文档与协议调整未重新烧录实机，也未重跑 PCB ERC/DRC。
