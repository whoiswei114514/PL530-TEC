# 温控与接口

本页描述根目录原版固件。独立新版的算法与新增接口见 [精密 PID 实验版](../firmware/precision_pid/README.md)，两版共用下述硬件保护与方向检测流程。

## 算法

温控采用“非线性接近 + 热平衡修正”算法。

在 PWM 高低温范围外，目标占空比可达 100%；接近目标时按误差曲线降低，占空比通过限速变化。进入平衡区时继承当前驱动，静止时才以约 10% 初值开始；随后依据温差和温升速率调整平衡驱动，允许低于 10%、为零或换向。10% 不是永久下限。

温度先滤波，正的逻辑占空比代表加热，负值代表制冷。`normal` 为 IN1 制冷、IN2 加热；`reversed` 交换两通道。冷热映射由 TEC 接线与探头安装决定，通过方向检测确认。

## 保护行为

- 启动始终保持 TEC 停用；保存温度参数和方向，不保存启用状态。
- 方向未知、初始化保护失败、有效温度缺失时，不允许正常驱动。
- 温度原始值越过 10/55 °C 时，在已启用且方向可信的条件下尝试全力纠正；无进展约 10 秒或最长约 30 秒后锁定停机。
- 采样超过 1 秒时，独立约 50 ms 软件定时器参与停机；硬件断电由外部开关完成。
- **有效温度恢复时，固件自动解除采样超时，并恢复超时前的启用状态。** 若应用要求故障后人工重启，需另行实现锁定策略。
- 驱动器故障、热失控和保护初始化失败不按同样方式自动恢复；初始化失败需排查后重启。
- 实机 `ESP_PLATFORM` 分支包含启动等待、故障毛刺过滤和额外停机延时，测试范围见 [发布验证](发布验证.md#测试范围)。

## 方向检测

由网页确认后手动启动检测：

1. 采集约 2 秒正向基线。
2. 实机 IN1 输出不超过 30% PWM，约 4 秒。
3. 停机约 18 秒。
4. 采集约 2 秒反向基线。
5. 实机 IN2 输出不超过 30% PWM，约 4 秒。

总超时约 60 秒。要求初始温度 15~45 °C，检测中触及 12/50 °C、超过设置的温度变化范围、样本无效或故障时停止。双向原始温差与漂移修正温差均需符号相反且达到约 0.2 °C，不能确定就失败。

检测前清除旧方向，结果成功保存后才应用，结束保持停用。网页停止在检测期间仍可提交，但网络和软件停止不替代硬件断电。

API 中 `rawDutyPercent` 是状态机的原始请求，可能显示 ±100；实际检测输出由 `dutyLimitPercent=30` 限幅，脉冲时长由 `pulseMs` 返回。

## 正常接口

设备使用 HTTP 80 端口。所有接口限制 Host 为 AP 地址或设备当前 STA IP；提供 Origin 时也必须与设备同源。写操作需 `X-PL530-Request: 1`。接口采用来源校验，无账户认证与 TLS，应在可信局域网内使用。

| 方法 | 路径 | 参数或内容 |
|---|---|---|
| GET | `/api/status` | 温度、状态、方向、PWM、传感器总线和 WiFi |
| POST | `/api/settings` | `target`、`high`、`low`、`enabled` |
| POST | `/api/control/stop` | 停用 TEC 并取消检测，不写启用状态 |
| POST | `/api/control/reset-fault` | 请求解除可解除的故障 |
| POST | `/api/control/detect-direction` | `confirm=full_power` |
| GET | `/api/wifi/scan` | 异步扫描，需要写操作请求头 |
| POST | `/api/wifi/connect` | `ssid`、`password` |
| POST | `/api/wifi/disconnect` | 请求断开并清除保存凭据 |

`confirm=full_power` 为兼容旧工具保留的协议值，实际检测仍按当前脉冲时长和占空比限幅执行。

参数需满足 `10 <= low < target < high <= 55`，目标与两边至少留 0.2 °C 间隔。`enabled` 接受 `true`、`false`、`on`、`off`、`1`、`0`，省略时按停用处理。

局域网请求示例：

```powershell
curl.exe http://192.168.1.1/api/status
curl.exe -X POST -H "X-PL530-Request: 1" -d "target=25&high=30&low=20&enabled=false" http://192.168.1.1/api/settings
curl.exe -X POST -H "X-PL530-Request: 1" http://192.168.1.1/api/control/stop
```

设备接口不开放到公网。主机网页测试使用网络拦截模拟设备，无需本机 HTTP 服务。
